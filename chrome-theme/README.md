# Catppuccin Espresso (Blur) — Chrome theme

Flat port of the Ghostty/Zed Espresso (Blur) theme. Chrome cannot render UI
blur or transparency, so this is a solid-color approximation of the palette.

## Install

Chrome cannot symlink an unpacked theme from `install.sh` — load it once by hand:

1. Open `chrome://extensions`
2. Enable **Developer mode** (top-right)
3. Click **Load unpacked**
4. Select this `chrome-theme/` directory

To update after editing `manifest.json`: go to `chrome://extensions` and click
the reload icon on the theme.
