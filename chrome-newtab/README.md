# Espresso New Tab (Chrome)

Minimal Catppuccin Espresso (Blur) new tab page — clock + web search.
Chrome themes can only recolor the default new tab page; fully replacing it
requires this separate `chrome_url_overrides` extension.

## Install

Load once by hand (Chrome cannot symlink unpacked extensions):

1. Open `chrome://extensions`
2. Enable **Developer mode**
3. **Load unpacked** → select this `chrome-newtab/` directory

Runs alongside the `chrome-theme/` extension (theme = colors, this = the page).
